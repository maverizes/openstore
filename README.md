# Birga — платформа всё-в-одном (GitHub Pages + Firebase)

Birga = **Benefit.uz** (где купить выгодно) + **Aloqa.uz** (чат по ID / телефону / email) + **Помощь** (FAQ, ИИ-агент, заявки админам) + **15 игр** + отдельная **админ-панель**.
GitHub Pages — статический хостинг, поэтому аккаунты, цены, чаты и заявки хранятся в бесплатном Firebase.

## Файлы
| Файл | Что делает |
|---|---|
| `index.html` | Главная: общий поиск по платформе + если не найдено — похожие сайты |
| `benefit.html` `benefit.js` | Benefit.uz: каталог, цены магазинов, совместимость, сборки, кабинет продавца |
| `aloqa.html` `aloqa.js` | Aloqa.uz: личные чаты, поиск по ID/телефону/email, ссылка-приглашение `aloqa.html#u=ID` |
| `help.html` `help.js` | FAQ, кнопка ИИ, заявки админам с перепиской |
| `games.html` `games.js` | 15 игр + таблица лидеров |
| `admin.html` `admin.js` `admin.css` | Админ-панель (другой дизайн) |
| `shared.js` | Шапка, тема, вход/регистрация, роли, «запомнить меня» |
| `ai.js` | Плавающий ИИ-агент, поиск, подсказки сайтов, вызов админа |
| `ai-worker.js` | (по желанию) прокси к Claude API на Cloudflare Workers |
| `catalog.js` | Товары, сборки, список игр, FAQ — правь здесь |
| `localdb.js` | Встроенная локальная база: включается сама, если Firebase не настроен |
| `firebase.js` | Конфиг Firebase и адрес ИИ-прокси |
| `firestore.rules` | Правила безопасности (роли проверяются на сервере) |

## Benefit.uz: демо и настоящие товары
Пока в базе нет ни одного настоящего товара, каталог показывает **5 демо-товаров** с вымышленными ценами (помечены «ДЕМО»). Как только продавец или админ добавит первый товар, демо исчезают сами.
Добавить настоящий товар: зарегистрируйся как продавец (или войди админом) → Benefit → «Мои цены» → «1. Добавить товар» → «2. Опубликовать цену магазина». Админ может удалять товары в админ-панели (раздел «Товары и цены»).
Раздел «Совместимость» и «Сборки» работает на отдельном справочнике деталей `PCP` в `catalog.js` — это не товары в продаже.

## Два режима базы данных
**1. Без настройки (по умолчанию) — локальная демо-база.** Просто открой `index.html` или выложи на GitHub Pages: регистрация, вход, роли, товары и цены, чаты Aloqa, заявки в помощь, игры с рекордами и админ-панель работают сразу. Данные хранятся в localStorage этого браузера, две вкладки синхронизируются вживую. **Первый зарегистрированный аккаунт автоматически становится Преадмином.** Чтобы увидеть чат между двумя людьми на одном компьютере — войди в двух вкладках под разными аккаунтами (сними галочку «Запомнить меня»). В шапке виден значок «Демо-база».
**2. Общая база Firebase — для настоящих пользователей на разных устройствах.** Выполни «Установку» ниже и вставь конфиг в `firebase.js` — `localdb.js` и значок «Демо-база» отключатся сами, а правила `firestore.rules` начнут защищать роли на сервере.
> Для показа инвесторам: локальный режим годится для демонстрации на одном устройстве. Перед запуском для реальных людей подключи Firebase.

## Установка (режим 2: Firebase)
1. https://console.firebase.google.com → Add project.
2. Authentication → Sign-in method → **Email/Password**.
3. Firestore Database → Create (production mode) → вкладка Rules → вставь `firestore.rules` → Publish.
4. Project settings → Your apps → Web → скопируй конфиг в `firebase.js`.
5. Загрузи все файлы в репозиторий GitHub → Settings → Pages → Deploy from branch.
6. Authentication → Settings → Authorized domains → добавь `<username>.github.io`.

## Первый Преадмин (ты)
1. Зарегистрируйся на сайте.
2. Firebase Console → Firestore → `users` → свой документ → поле `role` = `pre`.
3. Открой `/admin.html`. Дальше админов назначаешь из панели («Пользователи»).

## Аккаунты и «запоминание»
- Вход сохраняется на устройстве (галочка «Запомнить меня»; без неё — только до закрытия вкладки). Email подставляется при следующем входе.
- Профили, роли, ID, телефон, чаты, цены, рекорды лежат в Firestore — доступны с любого устройства.
- Тема, личные рекорды игр и последний открытый чат Aloqa помнятся в браузере.

## ИИ-агент
По умолчанию работает **встроенный базовый режим** (правила + поиск по сайту + подборка ПК + подсказки внешних сайтов).
Чтобы подключить настоящую модель Claude:
1. Cloudflare → Workers → создай Worker, вставь `ai-worker.js`.
2. Settings → Variables: `ANTHROPIC_KEY` (secret), `ALLOWED_ORIGIN` = `https://<username>.github.io`.
3. Адрес Worker вставь в `BIRGA_AI_URL` в `firebase.js`.
Ключ API никогда не кладётся в файлы сайта. Если ИИ-сервер не отвечает, виджет сам переходит в базовый режим и предлагает «Позвать админа».

## Роли
- **user** — цены, чаты Aloqa, игры, заявки в помощь
- **seller** — + публикует, меняет и удаляет свои цены
- **admin** — + блок/удаление предложений, правка цен, бан/разбан/удаление user и seller, ответы на заявки, чат админов
- **pre** — + назначает/снимает админов, банит их, ставит оценки 1–5, чистит чат админов

## Честные ограничения
- Телефон и email в Aloqa **не подтверждаются** (SMS-верификация платная, нужна отдельная настройка Firebase Phone Auth).
- Рекорды в играх пишет клиент — теоретически их можно накрутить.
- Удаление пользователя не удаляет его логин в Firebase Auth — для изоляции используй бан.
- Список пользователей читается целиком на каждой странице: для тысяч пользователей нужна пагинация.
